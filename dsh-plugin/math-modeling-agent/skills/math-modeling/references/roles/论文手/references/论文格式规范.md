# Word 论文格式规范

## 唯一权威来源

论文内容结构与格式必须遵循目标竞赛当届官方规则和官方模板。常用官方入口：

- 全国大学生数学建模竞赛：`http://www.mcm.edu.cn/`
- CUMCM 2026 论文格式规范：`https://www.mcm.edu.cn/upload_cn/node/775/cQMeL0YY905244c8bd4b9af832f1699446d8385e.pdf`
- MCM/ICM：`https://www.comap.com/contests/mcm-icm`

竞赛规则可能更新。生成前必须确认届次和官方文件版本，不能把本 Skill 的默认值当作永久规则。

### CUMCM 官方硬约束执行摘要（2026 版，已与官网 PDF 交叉核验）

以下条款出自 2026 年官方《全国大学生数学建模竞赛论文格式规范》（上方链接文件，核验于 2026-08），属于**硬约束**；未列入的样式项（字体/字号/行距/颜色）官方未统一规定，由本 Skill 默认值补齐：

**纸质版（如当届要求提交）**：

1. 第 1 页承诺书、第 2 页编号专用页、第 3 页摘要专用页、第 4 页起正文，从左侧装订。
2. **页码从摘要页起编，页脚居中，阿拉伯数字从 1 连续编号**。

**电子版**：

3. 不含承诺书与编号页，**第一页必须是摘要专用页**。
4. 单一文件，PDF 或 Word（官网建议 PDF），≤20MB，不压缩。
5. 支撑材料另交 RAR/ZIP ≤20MB，内含全部可运行源程序、自主查阅的数据、较大中间结果图表。

**结构与篇幅**：

6. **不得设置目录**。
7. 摘要原则上不超过一页。
8. 正文不超过 30 页（只计摘要页之后、附录之前；附录页数不限）。
9. 没有规定最低字数或最低页数——约 9000 字词单位（硬下限预警）与典型 9,000~15,000 字词单位、约 20 页只是本 Skill 的 CUMCM 完整度质量目标（取自近年国一实测约 9,000~16,000 字、正文 19~33 页），可由当届规则或用户要求覆盖。**禁止为凑字数填充**。

**附录（两条声明义务，最易漏）**：

10. 附录必须包含：支撑材料文件列表 + 全部完整可运行源程序（含 Excel/SPSS 等工具的交互命令）。
11. **没有用程序必须声明"本论文没有用到程序"；没有支撑材料必须声明"本论文没有支撑材料"**。

**匿名性**：

12. 摘要页、正文、附录任何位置不得出现参赛者身份、学校、赛区信息（含文档属性元数据）。

**页数口径**：页数必须以 DOCX 渲染成 PDF 后的实际页数为准，不能根据字符数猜测。

## 国赛排版基线（无官方模板时适用）

以下基线来自对近年国赛 A 题国一论文（2020/2022/2023/2024 共十余篇）的精读归纳，是大部分优秀论文的共性；当届官方模板或规则给出不同要求时，一律以官方为准。`paper_format.py` 的默认值已与本基线对齐。

### 字体、字号与对齐

| 元素 | 字体 | 字号 | 加粗 | 对齐 |
|---|---|---|---|---|
| 论文标题 | 黑体 | 三号（16pt） | 否（黑体自带） | 居中 |
| "摘 要" | 黑体 | 四号（14pt） | 否 | 居中 |
| 一级标题（一、二、三…） | 黑体 | 四号（14pt） | 黑体自带 | 居中 |
| 二级标题（5.1） | 黑体或宋体加粗 | 小四（12pt） | 是 | 左对齐顶格 |
| 三级标题（5.1.1） | 宋体或黑体 | 小四（12pt） | 是 | 左对齐顶格 |
| 正文 | 宋体（西文与数字 Times New Roman） | 小四（12pt） | 否 | 两端对齐，首行缩进 2 字符 |
| 图题 | 宋体 | 五号（10.5pt） | 否 | 图下方居中 |
| 表题 | 宋体 | 五号（10.5pt） | 否 | 表上方居中 |
| 公式 | Latin Modern Math；变量斜体，单位、算子（min/max/lim/log…）与公式内中文正体 | 与正文同级 | — | 公式必须**视觉居中**于版心（双制表位法：居中制表位+右制表位悬挂编号；禁用 oMathPara jc=center 与编号同段的写法，Word 实测退化为左对齐）；编号全文连续 (1)(2)…，禁止按章节编号 |
| 页码 | — | 五号 | 否 | 页脚居中，从摘要页起连续编号 |
| 附录代码 | 等宽字体（Consolas，中文注释宋体） | 8~9pt | — | 左对齐，单倍行距，带行号，语法着色（关键字蓝/注释绿/字符串暗红），细灰边框 |

- 行距：正文默认 1.35 倍（1.35~1.5 均在国一实测范围内；1.35 页面密度更接近近年国一主流）；公式段单倍行距；表格单元格单倍行距。字距：默认，不做加宽或压缩。
- 段前段后：正文 0；标题段距递减——一级标题段前 12pt/段后 6pt、二级 8/4、三级 6/3，且**标题与下段同页**（keep_with_next，禁止标题孤悬页尾）。
- **颜色纪律**：全文文字纯黑（标题、正文、题注、公式编号一律黑色）；彩色只允许出现在插图配色与附录代码语法着色中。
- 加粗只用于：标题、摘要中关键方法名与关键结果数字（Word 排版惯例，短语级、同一信息仅首次、不整句整段）、表格强调词、段落引导语；正文叙述句不大面积加粗。

### 图

- **编号铁律：全文按出现先后连续编号（图1、图2、图3…），绝对禁止章节连字符编号（图1-1、图5-2、图4.8 一律不许出现）；表与图分开各自连续编号（表1、表2…）；附录图表延续同样原则（附表1、附图1，或延续正文序号），同样禁止连字符**。子图共用题注"（左图）…（右图）…"。
- 图题在图下方居中，五号。
- 图宽约为版心 60~90%（`image()` 默认 12.5cm；近年 LaTeX 排版国一普遍 12.5~14cm），居中放置；图内文字渲染后不小于五号观感。
- 密度：建模求解部分约 0.6~1 幅/页；纯推导页可以无图，结果页可一页两图（整体 + 局部放大）。全篇（正文 20~30 页）图 15~25 幅、表 5~10 个为宜。
- 类型构成：每问 1~2 幅自绘几何/坐标系示意图；问题分析放全文思路流程图；求解配算法流程图；结果与灵敏度用彩色统计图；全篇统一色系。

### 表（"表格五律"）

1. **细三线**：顶/底线 1pt、表头分隔线 0.5pt，无竖线、无内部横线（数据密集大表可全框线）；粗线 1.5pt 以上即"肥大"感。
2. **紧凑**：单元格单倍行距、上下各约 1pt 呼吸、字号五号（10.5pt）；禁止把正文 1.35/1.5 倍行距带进表格。
3. **双居中**：单元格水平居中 + 垂直居中（vAlign）；表头加粗。
4. **不折行**：每行内容只占一行——列宽按内容分配（说明列加宽），说明文字精简（删括号注释），长元组写 `185.0/186.2/240.8/265.0` 或转置表格；写作层与工具层双管齐下。
5. **跨页完整**：首行设 tblHeader（跨页自动重复表头），行设 cantSplit（单行不跨页断裂）。

- 表题在表上方居中，五号（少数模板用"左对齐版心、零缩进"变体，如当届官方模板如此则从其模板）；表题不堆参数（工况参数进正文，不进表题）。
- 符号说明表：符号列用公式对象（斜体变量），说明列精简居中，单位列正体文本（写 `cm/min`、`m²/s` 式，负指数不用 Unicode 上标冒充）。
- 表内数据居中，**正文表给 4~6 位小数，附录答案表给全精度（8~9 位）**；科学计数法写 `×10⁻²` 公式形式，禁止 `1.26e-02` 程序式写法进表。
- 超宽表可用"…"省略中间列；参数表可用横排两行式（参数行/取值行）。

### 多数据呈现纪律（禁逗号堆积）

正文中 4 项及以上的并列数据、映射或分配关系（典型反例："无人机初始位置的 y 坐标：FY1(y=0)、FY2(y=1400)、FY3(y=-3000)、FY4(y=2000)、FY5(y=-2000)。据此分配：FY1→M1，FY2/FY4→M2，FY3/FY5→M3。"），禁止逗号一逗到底，按内容性质三选一：

- 属性—数值—去向类关系 → **小型三线表**（如：无人机 | 初始 y 坐标 | 分配目标）；
- 空间、结构、流程、分配类关系 → **示意图**（用 `tools/schematic` 产出 `diagram_qN_*`，在图上直接标注数据与编号，如无人机—导弹分配示意）；
- 计算型并列结果 → **换行对齐**或并入 `cases`/`aligned` 公式。

2~3 项零碎数据行内逗号并列即可，不必事事上表上图（过度呈现同样花哨失分）。判断标准：读者能否 3 秒内读出"谁对应谁"；读不出就换呈现方式。

### 附录版式

- 附录索引页："附录"居中（黑体）+ 清单；编号用"附录1/附录一/附录A"均可，与正文编号独立。
- 支撑文件列表：**两列表格**（文件名 / 功能描述，三线表，一行一条），不用"· 文件名——功能描述"点列长句；使用 AI 工具时《AI工具使用详情》列为清单一项（2025 国赛实测标配）。
- 代码：`code_block()`——Consolas 等宽 8~9pt，语法着色（绿注释/蓝关键字/红字符串），**中文注释密集**（参数逐行注单位），**带行号**（2025 国赛实测），细灰边框整框。
- 官方声明义务：没有用程序须声明"本论文没有用到程序"；没有支撑材料须声明"本论文没有支撑材料"。

## 模板驱动生成

推荐流程是“官方参考模板 + `python-docx` 内容构建 + OMML 公式 + 结构校验 + 渲染抽检”。

```python
from pathlib import Path
import sys

skill_root = Path("<SKILL_ROOT>")
sys.path.insert(0, str(skill_root / "tools" / "docx" / "scripts"))
import paper_format as pf

doc = pf.new_document(
    contest="cumcm",
    template_path=Path("<PROJECT_ROOT>") / "当届官方模板.docx",
    preserve_template_content=False,
)
pf.title(doc, "论文题目")
pf.abstract_title(doc)
pf.body_rich(doc, [("text", "摘要正文，"), ("math", r"\operatorname{RMSE}=1.85\ ^\circ\text{C}"), ("text", "。")])
pf.keywords(doc, "关键词一；关键词二")
pf.save_document(doc, Path("<PROJECT_ROOT>"), contest="cumcm")
```

常用构建函数：`title`/`abstract_title`/`keywords`、`heading1/2/3`（段距 12/6、8/4、6/3 递减，自动 keep_with_next）、`body`/`body_rich`（正文混排）、`equation(latex, number=)`（display 居中+编号）、`three_line_table`（表格五律）、`figure_caption`/`table_caption`（支持混排）、`image`（默认宽 12.5cm）、`reference_entry`（五号悬挂缩进）、`code_block`（等宽着色行号细灰框）、`page_number_footer`。

传入模板时，`paper_format.py` 保留模板的样式、分节和页面设置。官方模板含固定摘要页、编号页或占位符时使用 `preserve_template_content=True` 并在原位填充；只借用样式时使用默认值清除示例正文。未提供官方模板时，`cumcm` 和 `mcm-icm` 配置仅提供构建基线，必须再与当届官方规则核对。

## 公式

### 凡数学皆公式（判定规则）

摘要、正文、表格符号列、表头、图题表题中的数学字块一律用 Word 公式对象（行内 oMath），禁止用 Unicode 上下标（² ⁻⁶ ¹）、下划线（`v_max`）、尖角符（`x_i^e`）等文本冒充——这是近年国一论文与 LaTeX 范本的共同做法，也是观感差距最大的来源。

- **必须公式化**：凡含等号、不等号、上下标、希腊字母、运算符链、函数名（RMSE/min/max）、坐标元组、区间的字块——如 `RMSE=1.85 ℃`、`v_max=83.51 cm/min`、`(0, 200, 0)`、`(20000, 0, 2000)`、`[8.015, 9.415] s`、`y=0`、`y>0`、`t_r + \Delta t \leq T_arr`。坐标点、数值区间、带等号/不等号的片段看似"简单"，但只要含数学结构就一律公式化。
- **白名单（仅此三类可留文本）**：①【数字+单位且无数学结构】，如 20%、0.004 cm、60~120 s；②【纯英文字符串】，如 FY1、M2、result1.xlsx；③【字母+非下标语义的数字编号】，如 result2、Python3。白名单之外一律公式化；拿不准时按公式化处理。
- 写作接口：`body_rich(doc, [("text", …), ("math", r"…"), …])`；表格单元格、图题表题同样支持该混排 segments。

### 公式八条（居中大公式）

1. `paper_format.equation(doc, latex, number="1")` 产出**视觉居中**的 display 公式：居中制表位（版心一半，默认 4150 twips）+ 行内 oMath + 右制表位悬挂编号（默认 8300 twips = A4 + CUMCM 3.18cm 边距版心右端）。**禁止**用 oMathPara jc=center 与编号 run 同段的写法（Word 实测退化为左对齐）；编号公式渲染后必须抽检确认公式本体居中、编号在右端。
2. 公式字体统一 Latin Modern Math，字号 12pt 与正文一致（不随 docDefaults 缩小）。
3. 变量斜体；单位、算子（min/max/lim/log/ln/sin…）与公式内中文一律正体（转换器自动处理：`\text{}`/`\operatorname{}`/CJK 字符输出正体 run）。
4. display 模式下 ∑/∏/⋃ 上下限置于正上/正下（m:nary undOvr），min/max/lim 下极限置于正下方（m:limLow）；∫ 按中国教材惯例保持侧置；行内公式全部侧置，不撑大行距。
5. **多行公式纪律（禁逗号串联）**：多个约束、多个初始条件、多组并列数值禁止用逗号在一行内串联堆砌——三条件及以上的优化模型约束用 `\begin{cases}…\end{cases}`（大花括号竖排，一行一条）；连等/递推计算过程用 `\begin{aligned}…\end{aligned}`（一行一句、`&=` 等号对齐）；行距均匀、公式段单倍行距。只有两三条且极短（如 `x=1, y=2`）时才允许逗号并列。
6. "式(10)全部约束"类中文说明移出公式本体，写入正文行。
7. 公式必须可编辑，不能是截图或纯文本 LaTeX；编号全文连续且样式统一。
8. 复杂公式优先使用 Pandoc 的成熟 LaTeX→OMML 转换，再进行 DOCX 校验。

支持常用希腊字母、关系符号、反三角函数、分式、根式、上下标、矩阵与分段表达式，包括 `\nu`、`\mu`、`\approx`、`\arcsin`、`\arccos` 和 `\arctan`；未知命令、未闭合分组和不支持环境会明确失败。

## 完整 LaTeX 论文转换

```powershell
python ../../../../tools/docx/scripts/equations.py convert-latex "<PROJECT_ROOT>/完整论文-LaTeX/main.tex" --output "<PROJECT_ROOT>/完整论文.docx" --template "<PROJECT_ROOT>/当届官方模板.docx"
```

该命令需要系统已安装 Pandoc，使用 citeproc 处理 BibTeX 引用，将公式转换为原生 OMML，递归展开项目内的 `\input`/`\include`，并从 LaTeX 项目目录读取相对图片。任何 Pandoc 警告默认阻断 DOCX 发布；只有逐项检查后才能同时使用 `--allow-warning` 和 `--override-reason`。成功转换会生成 `.conversion.json`，用于核对输入、输出、模板哈希、Pandoc 版本和复现命令；交付前运行 `equations.py verify-conversion "<PROJECT_ROOT>/完整论文.docx"` 重新计算全部哈希。自定义宏、浮动体、交叉引用和参考文献样式仍须人工核对；未提供 CSL 时尤其要检查引文样式。输出仍需执行本规范后续的结构校验和渲染抽检。

## 表格与图

- 表格必须可编辑；三线表使用 `three_line_table()`（默认已满足"表格五律"：细线、单倍行距、双居中、跨页重复表头、行不跨页断裂、按内容列宽）。
- 图来自编程手真实运行结果，可从候选图中选择。
- 每幅图和每个表必须有编号与题注，并在正文中至少引用一次；编号遵守"编号铁律"（图节）：全文连续、图表分编、禁止章节连字符；单位和数值必须一致。

issues = pf.validate_paper_structure(doc, contest="cumcm", rendered_pages=实际页数)

该检查会报告篇幅、公式/图/表数量、图表编号与正文引用、参考文献双向对应以及页数问题。默认 9000 字词单位、20 页、公式 5 个、图 8 幅、表 3 个均为 CUMCM 完整度质量目标；其他竞赛同样默认至少 8 幅正式图。2026 年 CUMCM 正文 30 页上限属于已经核验的官方硬约束。使用其他届次或竞赛时必须传入相应阈值；降低默认目标必须记录官方条款或用户要求。OOXML 校验通过后仍需渲染抽检，因为 XML 合法不等于版面正确。
