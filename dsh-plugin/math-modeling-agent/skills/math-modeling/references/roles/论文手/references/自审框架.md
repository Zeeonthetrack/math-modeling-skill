# 论文自审框架

本清单是论文手的作者自检，不替代 `W1`、`W2` 独立 Subagent 验收。

## 一、官方规则

- [ ] 已记录目标竞赛、届次、官方规则和官方模板来源。
- [ ] 页面、摘要页、编号、页数、字体、提交格式等逐项符合当届官方文件。
- [ ] 未把本 Skill 默认值或往届经验写成官方规定。
- [ ] 无目录；页码从摘要页起、页脚居中连续编号；正文 ≤30 页（不含摘要页与附录）。
- [ ] **匿名性**：摘要页、正文、附录及文档属性元数据中无参赛者身份/学校/赛区信息（身份扫描只报告，疑似项人工判定——校名可能是研究对象或参考文献）。
- [ ] 附录含支撑材料文件列表与全部可运行源程序；**无程序已声明"本论文没有用到程序"，无支撑材料已声明"本论文没有支撑材料"**。

## 二、内容与证据

- [ ] 长篇正文前的证据大纲已由独立质检 Subagent 执行 `W1` 并返回 `PASS`。
- [ ] 每个结论都有真实代码结果、图表、公式或文献支撑。
- [ ] 摘要中的数值与正文、表格、图和复现清单一致。
- [ ] 摘要符合目标竞赛范式：CUMCM 为国赛叙事链（总述段 + 任务单元段"针对问题X/在问题X基础上…建立…采用…得到…"，五要素闭环、结果紧跟方法、每问 1~3 个关键数值 + 关键词 3~5 个，750~1000 汉字、3~6 段独立第一页）；MCM/ICM 为四段式（问题挑战/方法/关键结果/验证创新）。结论段"一图一数一句"；对照 `写作规范.md` 第二节反模式自查（摘要无定量结果、只报数字不解读、图表无编号等）。
- [ ] 摘要信息损失六类自查通过：无"有模型没结果/有结果没数值/有创新没体现/有检验没说明/方法过多结果过少/各问篇幅失衡"；摘要数字保留正文原精度、带对象与单位；赛题指定输出文件（如 resultN.xlsx）已在摘要相应问末尾点名。
- [ ] 每道子问题最多两个独立模型体系；物理模型的不同近似按模型族说明清楚。
- [ ] 主体章按问题联动（每问"模型建立→模型求解→结果与分析"），不是"先全部建模、再全部求解"两段式；公共底座不超过 1.5 页。
- [ ] 问题分析按问题逐问前瞻书写（本质+难点+拟用方案+方法选择理由），未搬运中间产物原文，无求解后的后见之明。
- [ ] 模型假设 4~8 条、每条一句话，至多半句必要性说明。
- [ ] 领域术语与方法名首次出现处有一句话解释；符号首次使用自然带出。
- [ ] 密度纪律双向达标：每问有公式+图表+结果解读，关键算法有伪代码/步骤/流程图；每问仅 1~3 个关键数值做多维讨论，无超过 6 个数字的段落。
- [ ] 机器视角清零：全文扫描无表格播报腔、元指令泄露、占位符残留、工作日志式标题、机器自述。
- [ ] 深度 AI 痕迹扫描通过：同一概念全文术语统一（无同义词轮换）；无悬浮式"从而/进而"连挂；无成对转折收束模板；无虚假范围与公式化挑战段；破折号每段 ≤1 个；无冒号串联 3 项以上长列举；句长长短交错。可用 `tools/docx/scripts/aigc_scan.py` 对正文提取文本做辅助扫描（启发式，仅提示需人工判定的位置，不作为否决依据）。
- [ ] 没有虚构背景数据、赛题阈值或未核验引用。
- [ ] 局限和适用边界具体、可追溯，含真实负面结果；优缺点拒绝"运行快、精度高"式空话。
- [ ] 附录含三大件：索引清单（支撑文件名+功能注释，使用 AI 时含《AI工具使用详情》）、答案全精度大表、按问题分文件的核心代码（带行号）；正文结果 4~6 位小数、附录全精度。
- [ ] 当届规则要求 AI 披露时，正文角标、参考文献 AI 工具条目、《AI工具使用详情》三件齐备。

## 三、文档结构

- [ ] Word 分支的公式是可编辑 OMML；用户显式要求 LaTeX 时，LaTeX 分支的公式是可编译源码。无公式截图。
- [ ] 同时生成两种格式时，Word 与 LaTeX 的正文、数据、图表、公式和结论一致。
- [ ] 已分别核对 PDF 总页数、正文起始页、附录起始页和正文页数；官方正文上限未错误计入摘要或附录，官方硬约束和非官方质量目标已明确区分。
- [ ] 默认至少包含 8 幅正式图，其他竞赛与 CUMCM 使用同一图数基线；若按官方规则或用户要求调整，已记录依据。
- [ ] 每个子问题至少有 1 幅正式图支撑关键结论，没有把全部图集中在问题一或单一子问题。
- [ ] 表格可编辑，每幅图和每个表都有连续编号、题注及正文引用，没有孤儿图表。
- [ ] 图题在图下方、表题在表上方（五号居中）；**图表编号铁律**：全文按出现先后连续编号（图1、图2…/表1、表2…），图表分编，无章节连字符（图1-1、图5.2、表5-1 一律不许出现），附录图表用"附表1/附图1"或延续正文序号；公式编号全文连续 (1)(2)…。
- [ ] **凡数学皆公式**：全文扫描无文本冒充公式——无 Unicode 上下标（² ⁻⁶ ₁）、无下划线/尖角符写法（`v_max`、`x_i^e`）、无程序式科学计数法（`1.26e-02`）；摘要、正文、符号表、表头、图题表题中含等号/不等号/上下标/希腊字母/运算符链/函数名/坐标元组/区间的字块（含 `(0, 200, 0)`、`[8.015, 9.415] s`、`y=0` 这类"看似简单的"）均为行内公式对象；白名单仅三类：数字+单位、纯英文字符串、字母+非下标数字编号。
- [ ] **大公式 display 排版**：全部编号公式**视觉居中**于版心（双制表位法，渲染抽检确认非左对齐）；∑/∏/⋃ 上下限正上正下、min/max/lim 下极限正下方、∫ 侧置；公式内中文与算子正体（无斜体中文）；公式字体 Latin Modern Math、字号与正文一致；编号右端、无折行漂移。
- [ ] **多行公式与数据呈现**：三条件及以上约束用 cases 大花括号竖排（一行一条），连等/递推计算用 aligned 等号对齐（一行一句），无逗号一行串联的公式堆；正文 4 项及以上并列数据/映射/分配关系已改用三线表、示意图（diagram_qN_*）或换行对齐呈现，无逗号一逗到底的段落（2~3 项零碎数据除外）。
- [ ] **表格五律**：细三线（顶/底 1pt、表头 0.5pt）；单元格单倍行距、水平+垂直双居中；每行只占一行（无折行，说明列无冗长括号注释）；跨页表首行自动重复、行不跨页断裂；符号表符号列为公式斜体、单位列为正体文本。
- [ ] 图宽约为版心 60~90%（`image()` 默认 12.5cm），图内文字渲染后不小于五号观感；建模求解部分约 0.6~1 幅/页；全文文字纯黑，彩色仅出现在插图与附录代码中。
- [ ] 附录代码为 Consolas 等宽 8~9pt、带行号、语法着色（蓝关键字/绿注释/红字符串）、细灰边框、单倍行距；支撑材料清单为两列三线表（文件名/功能描述）。
- [ ] 正文行距 1.35 倍；参考文献条目五号、悬挂缩进、1.15 倍紧凑行距。
- [ ] 参考文献与正文引用双向对应，DOI 和出版信息已核验。
- [ ] 不含 `[待补充]`、模板示例正文或临时占位符。

## 四、技术验证

- [ ] Word 分支的 `self_check.py` 和 `office/validate.py` 通过。
- [ ] LaTeX `doctor`、真实编译和资源/源码/PDF 校验全部通过；无未解析引用或文献，全部子问题有正式图，代码与图表副本未漂移，PDF 构建清单与当前源码哈希一致，空白页、页面尺寸、字体嵌入和图片 DPI 合格。
- [ ] LaTeX→DOCX 转换无未批准 Pandoc 警告，`.conversion.json` 的输入、输出和模板哈希与实际文件一致。
- [ ] 渲染抽检通过，分页、页眉页脚、公式和图表无异常。
- [ ] 默认交付 `完整论文.docx`；用户显式要求时同时交付完整 LaTeX 源码项目及其编译 PDF。
- [ ] 所需格式冻结后已由独立质检 Subagent 执行 `W2` 并返回 `PASS`。
- [ ] `W1`、`W2` 通过后相关正文、数据、图表和规则未发生未经复验的实质变化。
