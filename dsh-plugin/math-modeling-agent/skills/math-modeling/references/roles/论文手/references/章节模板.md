# 论文章节模板

章节名称和顺序首先服从当届官方模板。官方没有固定章节时，CUMCM 使用下面的国赛八股骨架（来自近年国一论文共性），MCM/ICM 按 `英文化工作流.md` 与当届官方模板组织。不要机械套用所有章节，但 CUMCM 的问题重述 / 问题分析 / 模型假设 / 符号说明 / 按问题求解 / 评价一个不能少。

## CUMCM 八股骨架

```
论文标题（黑体三号居中）
摘 要（独立第一页，含关键词）
一、问题重述
二、问题分析
三、模型假设
四、符号说明
五、模型的建立与求解（按问题联动）
六、模型评价
参考文献
附录
```

### 摘要（独立第一页）

按 `写作规范.md` 第二节第 1 条的国赛叙事链：总述段（背景式或公共基础式）→ 任务单元段（默认逐问"针对问题X，……建立…采用…得到…（1~3 个关键数值）"，后问可用"在问题X模型基础上加入……"递进，共享模型的分问可合并，按场景/阶段/模型链组织亦可）→ 可选收束句（无新总体结论则自然结束）→ 关键词 3~5 个。750~1000 汉字、3~6 段；每段走"任务/瓶颈→决定性处理→核心模型→关键结果→结论/验证"闭环，结果紧跟方法；按题型取对应主干（机理/优化/预测/评价/分类/统计/运筹，见写作规范题型主干表）。赛题显式指定的输出文件在相应问末尾点名。

### 一、问题重述（约 700~800 字）

1.1 问题背景：从现实场景切入，2~4 句，可带文献引用。
1.2 问题提出：描述本题对象与已知参数，"需解决以下问题："后逐问复述（"问题一："引导）。复述不是照抄题面：把长句拆顺、补出参数含义。含几何/结构参数的题，可在本节插自绘尺寸标注图，把题面参数工程图化。

### 二、问题分析（约 600~900 字）

两种体式二选一：段落式（"对于问题一，……"每问一段 150~250 字）或小节式（"2.1 问题一的分析"）。前瞻式：一句复述该问要求 → 定性（优化/机理/几何求交问题）→ 思路链（首先…接着…然后…最后）→ 难点与方法选择理由（"先破后立"句式）；递进写明"在问题X基础上添加……约束/改进……"。禁止搬运中间产物原文，禁止写入求解后才知道的结论。可在本节开头放一张各问题关系图/全文思路流程图。

### 三、模型假设（4~8 条）

编号列出，每条一句话，至多半句必要性说明；删除"影响范围"式论文腔。

### 四、符号说明

三列三线表：符号 / 说明 / 单位。排版纪律（对标省一与国一符号表的精致观感）：

- 符号列一律用公式对象（斜体变量、正体下标文字，如 `T(x,t)`、`\tau_{150 \to 190}`、`\theta_i`），不用 Unicode 文本冒充；
- 说明列精简居中——删括号注释与参数堆叠（"温区组设定温度"即可，不要"温区组设定温度（θ1：…θ4：…）"），每条只占一行；
- 单位列正体文本，写 `cm/min`、`m²/s`、`W/(m·K)` 式，不用 Unicode 负指数上标；无单位填"/"；
- 表格满足"表格五律"（细三线/单倍行距/双居中/不折行/跨页重复表头），用 `three_line_table()` 的混排 segments 写入。

符号多时可双栏并排省空间；题面专有名词可先给一句文字定义再列符号。

### 五、模型的建立与求解（每问 3~8 页）

两种组织法二选一：(a) 一个大章内 5.x 每问一节；(b) 问多时每问独立一章。每问内部三段式：

- **模型建立**：动机 → 示意图 → 符号引入 → 推导 → 模型总成；优化类问题逐条命名约束（"任务分配约束：……"约束名加粗），末尾设"模型汇总"小段把目标函数 + 全部约束合成 max/min + s.t. 块。
- **模型求解**：Step1/2/3 步骤分解或算法流程图；关键算法给伪代码（带行号）；数值求解写清"先粗后精"的步长与区间；采样精度/步长灵敏度交代可放在求解小节开头。
- **结果与分析**：表 + 图 + 解读段；图前有引入句、图后有"图元含义 + 发现 + 机理"；整体图后接局部放大图；超大结果表正文放部分、全量见支撑材料（精确到工作表）；赛题指定输出文件（如 resultN.xlsx）在结果节点名交付。

多问共用底座（坐标系、通用控制方程）可前置，不超过 1.5 页。

### 六、模型评价（1~2 页）

6.1 检验与灵敏度：灵敏度曲线族 / 参数扰动图；检验条目与被检验假设一一对应；也可把灵敏度并入各问末节。
6.2 模型的优点：2~4 条，每条一句且带证据。
6.3 模型的缺点与改进：1~3 条，写真实负面结果与失效边界。
（可选）模型推广：数条编号要点。

### 参考文献

5~10 条按需引用，GB/T 7714 格式，悬挂缩进，正文角标与文末条目双向对应。CUMCM 当届规则要求时，AI 工具条目与文献共享编号序列（格式见 `写作规范.md` 第三节第 6 条）。

### 附录（三大件）

1. 附录索引页 + 支撑材料文件清单（文件名 + 功能注释；使用 AI 工具时含《AI工具使用详情》）；
2. 答案完整大表（全精度 8~9 位小数；正文只给 4~6 位）；
3. 核心代码（按问题分文件，语法着色，中文注释密集，带行号，删非核心噪音，零解释）。
正文放不下的长推导可作为"公式推导"附录。没有用程序须声明"本论文没有用到程序"；没有支撑材料须声明"本论文没有支撑材料"。

## 各章展开通则

- 每个子问题最多两个独立模型体系；同一物理机制的基础近似和高精度展开按一个模型族组织。按"变量与参数 → 假设依据 → 数学定义 → 算法 → 运行参数 → 实际结果 → 验证"展开。模型选择以题目适配和证据为准。
- 每个主张紧跟真实表格、图或数值输出。置信区间、p 值、误差和改进幅度都由代码计算，并与复现清单一致。
- 语言、密度、摘要、反模式与合规要求统一按 `写作规范.md`；字体、图表、编号与版面按 `论文格式规范.md` 的国赛排版基线。
